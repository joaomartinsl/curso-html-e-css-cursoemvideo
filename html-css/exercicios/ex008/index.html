Itálico / Ênfase

Nesta frase, temos um termo em itálico usando a tag <i> (NÃO SEMÂNTICO)

Já nesta frase, temos um termo em ênfase usando a tag <em> (SEMÂNTICO)

Texto marcado

Podemos também criar um texto marcado utilizando a tag <mark>

E nessa parágrafo, temos outro texto marcado.

Texto grande e pequeno

Estamos criando um texto grande e um texto pequeno nesse parágrafo usando <big> (OBSOLETO) e <small>

Texto deletado
